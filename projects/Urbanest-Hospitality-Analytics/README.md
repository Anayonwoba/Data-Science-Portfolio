**Urbanest Hospitality Analytics**



**Project Overview**



Urbanest Hospitality Analytics is a Data Science project focused on analysing hospitality data to uncover meaningful insights and support data-driven decision-making.



**Project Objectives**



\- Explore and understand the hospitality dataset.

\- Identify patterns, trends, and meaningful relationships.

\- Generate actionable insights from the data.

\- Apply predictive modelling to hospitality-related data.



**Tools \& Technologies**



\- SQL

\- Python

\- Exploratory Data Analysis (EDA)

\- Machine Learning



**Project Workflow**



1\. Data Understanding

2\. Data Cleaning and Preparation

3\. Exploratory Data Analysis

4\. Feature Engineering

5\. Model Development and Evaluation

6\. Insights and Recommendations
